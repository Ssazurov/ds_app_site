Солнечный мир: карточки и социальные истории для детей с синдромом Дауна

Бесплатное приложение для занятий дома с родителями: картинки с озвучкой, короткие истории от первого лица (например, «Я мою руки»), подбор материалов по возрасту ребёнка.

Открыть приложение в браузере

Для родителей

  • Приложение работает без интернета после загрузки и не требует регистрации.
  • Мы просим только имя (можно псевдоним) и возраст ребёнка в годах. Эти данные остаются только на вашем устройстве и никуда не отправляются.
  • Диагноз и другие сведения о здоровье вводить не нужно.
  • Можно создать несколько профилей. Профиль удаляется в родительском разделе.

Приложение не заменяет занятия со специалистом и не является медицинской рекомендацией. См. дисклеймер.
